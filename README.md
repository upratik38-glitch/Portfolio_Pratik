# Pratik Ugale — Portfolio

A responsive personal portfolio website created from the information in the supplied resume.

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Inter)

## Files

```text
pratik-ugale-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

Open `index.html` in a browser.

For a local development server with Python:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deploy on GitHub Pages

1. Create a new GitHub repository, for example `pratik-ugale-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`.
7. Click **Save**.
8. GitHub will publish the site at your GitHub Pages URL.

## Important

The portfolio intentionally uses only information supported by the supplied resume. The resume contains a Certifications heading but no individual certification names, so no certifications were invented.

Before publishing, replace or update any details you want to change, especially:
- email / phone
- LinkedIn URL
- GitHub username
- project descriptions
- education dates
- certification details
